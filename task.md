# SOLESTE: THE ENCHANTED PALACE 🏰✨

**Objective**: Create a "Dewa-Level" digital experience that feels like a magical journey into a royal palace. The target is Awwwards-grade quality with Disney-inspired magical vibes.

---

## 🎨 Design System: "Royal Gilded Marble"
- **Primary**: Cream Marble (`#FDFBF7`)
- **Accent**: Burnished Gold (`#D4AF37`)
- **Secondary**: Royal Silk White (`#FFFFFF`)
- **Deep Accent**: Midnight Emerald (`#013220`) for contrast sections.
- **Typography**: 
  - Headings: `Cormorant Garamond` (Elegant Serif)
  - Subheadings: `Playfair Display` (Classic Serif)
  - Body: `Inter` (Modern Sans-Serif)

---

## 🛠 Tech Stack
- **Engine**: Nuxt 3 (SSR + Hybrid)
- **Motion**: GSAP (ScrollTrigger, Flip, SplitText)
- **Fluidity**: Lenis (Smooth Scrolling)
- **Styles**: Tailwind CSS
- **Interactions**: Framer Motion (Vue version or custom GSAP)
- **Vfx**: Canvas-based particle system (Magic Dust)
